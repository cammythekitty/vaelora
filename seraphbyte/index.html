What's inside

A lean Rust stack.

No Python, no PyTorch. The engine is built on Candle, Tokio and the HuggingFace tokenizers crate, with my own server and inference loop on top.

Model-accurate tokenizer
Loads the model's own tokenizer.json with the HuggingFace tokenizers crate, so vocabulary and special tokens match the model exactly.
Quantized weight loader
Loads quantized GGUF models through Candle, keeping the VRAM footprint small for constrained hardware.
WebSocket streaming
Tokens stream to the client one at a time over a WebSocket. Seraphine runs on it live.
Fine-tune friendly
Built to serve fine-tuned models. Seraphine's personality is trained into the weights, not injected through a runtime prompt.
Self-hosted by default
No cloud and no outbound telemetry. Your model, your hardware, your data.
Rust core
The server and inference loop are Rust from end to end, with no Python or scripting layer. Candle handles the model math and CUDA.

Architecture

The stack, top to bottom.

A short stack with nothing hidden: every layer is open source and runs on your own machine.

WebSocket client (browser or bot) ws
SeraphByte WS server rust

Quantized weight loader (GGUF) candle

GPU / CPU (consumer hardware) hw
example.rs
// simplified example, not the real source let engine = Engine::load(Config { model: "./models/seraphine-q4.gguf", quant: Quant::Q4_K_M, ctx_len: 4096, })?; let server = WsServer::bind("0.0.0.0:9001")?; for conn in server.incoming() { let eng = engine.clone(); tokio::spawn(async move { eng.stream_to(conn).await }); }
  • Streams tokens as they're generated
  • Multiple concurrent connections
  • KV cache shared across sessions
  • No Python runtime in the process tree
