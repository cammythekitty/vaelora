Hi, I'm Cammy

I'm a self-taught developer. I write Rust, run Linux on everything, and build things from scratch so I understand every part of them.

I got into code because it looked fun to a younger me. So I just started, with no tutor and no course, and kept building upwards from there.

That's still how I work. When something catches my interest, I learn how it works underneath and then build my own version, whether that's a black hole raytracer or the tools that keep my homelab running.

Right now I'm learning C++. Rust is still home, but I want to know the other side too.

I'm also a trans girl. I'd rather be all of myself here than a tidier, quieter version. If you're trans too and want to get into code, or you're already in it, you're very welcome here.

I also stream on Twitch, where you can watch things get built, broken and fixed again.
