Projects

Things I've built and am building, and what each one is made of.

Black hole raytracer

A real-time black hole you can fly around. Every pixel's light ray is bent through curved spacetime on the GPU.

The accretion disk is layered 3D noise with Doppler beaming and gravitational redshift, coloured by temperature. It can save screenshots up to 128K by rendering in tiles. The 128K one needs about 34 GB of free RAM, so it's mostly there because it could be.

Built with Rust, wgpu, WGSL

In orbit

Everything else

  • systemd-mgr

    Portainer, but for systemd. One dashboard to start, stop and watch services on every box in my homelab, without opening inbound ports on any of them. Its MeshMon plugin connects machines behind NAT with hole punching and a relay fallback. An earlier version is open source as systemdtainer.

    Built with Rust, Tokio, WebSockets, PostgreSQL, JavaScript

    On the pad

  • stockfish-ui

    A fully local chess app around Stockfish: a native window, no browser, no network. Real clocks, an analysis board, a position editor and a blunder report after every game, packaged for Linux, Windows and macOS.

    Built with Rust, wry, tao

    In orbit

  • mc-relay

    A relay so friends can join a Minecraft server at home that has no public IP. A small VPS takes the connection and passes it home over WireGuard, so nothing at home is exposed. Built, not running yet.

    Built with Rust, Tokio, WireGuard

    On the pad

  • aetherOS

    The build system for my own Linux distribution. It compiles a kernel from source and boots it in QEMU for testing. Early days.

    Built with Rust, QEMU
